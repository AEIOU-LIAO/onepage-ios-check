# onepage-ios-check

用 Playwright 的 WebKit（Safari 的内核），按 iPhone 的屏幕尺寸、触摸方式和浏览器标识，检查线上的 OnePage。

## 怎么跑
- Actions → 「iPhone（WebKit）检查」→ Run workflow（只在手动触发时运行）
- 结果：这次运行页面上的小结；报告和截图在 Artifacts（`ios-check`）里，最近一次的也在 `results` 分支

## 检查什么
| 组 | 内容 |
| --- | --- |
| 登录、刷新后恢复 | 登录 → 加一条待办 → 刷新后仍是登录状态、待办还在 → 删掉 |
| 页面操作 | 整页不能放大的三道设置、横竖屏切换后字号 / 缩放 / 横向溢出、对话框打开与关闭按钮位置、菜单和历史不叠在一起、对话框打开时下面的毛玻璃关掉 |
| 聊天记录同步 | 设备 A 写入一段记录 → 设备 B 的历史里能看到、内容完整 → B 删除 → A 也消失 |

只用测试账号；不提问，不消耗 AI 额度；测试中写入的待办和记录结束时都会删掉。

## 自动检查查不到、必须用真 iPhone 看的
这里跑的是电脑上的 WebKit，不是 iPhone 本身。下面这些只能靠真机：
- 从主屏幕图标打开（独立窗口模式）特有的行为：登录状态保留多久、切到别的 App 再回来是否重新加载
- 内存不足被系统杀掉后页面重开
- 真实手势：双指缩放、长按拖动卡牌 / 盆栽、屏幕边缘右滑返回、手感
- 毛玻璃的模糊效果：这个环境的截图里画不出模糊（卡片后面的背景是清晰的），所以「看起来够不够朦胧、文字会不会和后面的内容混在一起」要在真机上看
- 真实旋转屏幕时系统对文字的自动放大（这里只能改窗口宽高来模拟，并检查相关设置是否生效）
- 系统键盘弹出时的遮挡、听写、长按说话（麦克风）
- 锁屏 / 切后台时回答中断与续接、后台播放声音
- 刘海 / 灵动岛的安全区域、低电量模式

## 安全
- 仓库公开：只有检查脚本，没有网站代码
- 账号在 Settings → Secrets（`TEST_USER`、`TEST_PASS`），脚本不打印它们；不录像、不留 trace
- 截图会把显示用户名的位置、测试账号里原有的对话标题和待办盖住；报告里出现账号文本会被替换成 `***`
- 截图任何人都能下载：测试账号里不要放私人内容
